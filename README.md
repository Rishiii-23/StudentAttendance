# StudentAttendance
Student Attendance Management System
## About the Project

Student Attendance Management System is a web-based application developed to manage student records and attendance efficiently.

## Features

- Add Student
- View Students
- Edit Student Details
- Delete Student
- Mark Attendance
- View Attendance
- Calculate Attendance Percentage

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Put the project folder inside `C:\xampp\htdocs\`.
4. Create the required database in phpMyAdmin.
5. Open the project in the browser:

`http://localhost/StudentAttendance/`
